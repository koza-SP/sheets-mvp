# 公開ロードマップ + Stripe設定(2026-10-13)

## 1. 今の状態(確認済み、2026-10-13)

このサイトは**既に世界に公開済みで、実際に買える状態**です。

- サイト: https://koza-sp.github.io/sheets-mvp/ (HTTP 200、稼働中)
- 商品3点、それぞれ本物のStripe決済ページに直リンク(test cardで実購入できる状態)
- 国の制限は一切していないので、**世界中どこからでも今すぐ買える**(Stripe Payment Linkは国を絞らない限りデフォルトで全世界対応)

「公開までの手続き」という意味では、ここまではもう終わっています。残っているのは「買った記録をスプレッドシートに自動で残す」部分だけで、これは`go.sh`実行待ちのままです(売る/買う自体は今でもできます)。

## 2. シンプル化の考え方

複雑にしないために、今の構成を「土台」として固定し、後から足していく形にします。

```
土台(今、完成済み):  静的ページ + Stripe決済リンク = 世界中から買える
          ↓ 足す1: 注文を自動記録(Googleスプレッドシート、go.sh待ち)
          ↓ 足す2: 英語ページ(海外客向け)
          ↓ 足す3: 配送先国ごとの送料表示
```

土台を壊さず上に足すだけなので、いつでも今の状態で止めても「ちゃんと売れるサイト」のままです。

## 3. 国別ロードマップ(どこから始めるか)

**結論: 国を絞らず「全世界」から始めます**(絞る方が逆に複雑になるため)。

| Phase | 内容 | 対象国 | 理由 |
|---|---|---|---|
| 0(完了) | 日本語ページ+JPY価格+Stripe決済 | 全世界(無制限) | Stripe Payment Linkは国指定なしでも海外カードを自動で受け付ける。絞る設定を足す方が今は余計な作業になる |
| 1(次) | 英語ページ追加(同じ商品、説明だけ英訳) | 英語圏(米国中心) | 日本の工芸品は英語圏の需要が最も厚く、Stripeの英語対応も最も成熟している。新しい決済手段は増やさず説明文だけ変える最小変更 |
| 2 | スプレッドシート自動記録(go.sh実行後) | 全世界共通 | 注文管理の自動化、国によって処理は変えない |
| 3 | 配送先国ごとの送料表示 | 需要が見えてきた国から都度追加 | 実際に買われた国のデータを見てから決めた方が無駄がない(推測で先に作らない) |

## 4. Stripe設定について

**新しいStripeアカウントの作成は不要です。** 今使っているアカウント(`japan-global-ec`本体と共用、test鍵`sk_test_51U3...`)がそのまま使えて、既にPayment Link 3件が動いています。「作成」が必要なのは、新しい商品を追加するときの「Product/Price/Payment Link」の3点セットだけで、これは私がStripe APIで直接作れます(ダッシュボード操作不要、Yuの作業は無し)。

### Yuに必要な操作(今の時点でゼロ)

- 本番(live)決済に切り替える時だけ、Stripe側の本人確認(運転免許証等のアップロード)が必要になります。これは「実際にお金を受け取る」段階の話で、今のtest mode運用には不要です。
- それ以外は全て私の方で完結できます。

### 新商品を追加したい場合の手順(私が実行、Yuは商品情報を伝えるだけ)

1. Yu: 商品名・価格・説明文・画像を伝える
2. 私: Stripeで Product + Price + Payment Link を作成(API、数秒)
3. 私: `public/data/products.json` に追記、commit + push
4. GitHub Pagesは数分で自動反映、追加作業不要
